title: Related projects
description: How CSM fits into the MatchZy ecosystem.
---

CS2 Server Manager is designed to work closely with:

- MatchZy Auto Tournament (web UI + API orchestration)
- MatchZy Enhanced (in-server automation plugin)

If you’re running structured tournaments, you typically want CSM + MatchZy Enhanced on the servers, and MatchZy Auto Tournament on top for orchestration.
