CS2 Server Manager (CSM) can help you keep your CS2 servers up to date with minimal downtime.

## When you should update

Update when either:

- you see a **CS2 update required** warning in MAT, or
- players can’t connect after a Valve update, or
- you know Valve shipped an update and want to update before your next matches.

## Quick update (recommended)

```bash
sudo csm update-game
sudo csm restart
```

This updates the shared game install and restarts servers.

## Install the cron monitor

If you want CSM to automatically run checks on a schedule, install the monitor cron job:

```bash
sudo csm install-monitor-cron          # default */5 interval
sudo csm install-monitor-cron "*/10"   # custom interval
```
