ME (MatchZy Enhanced) runs **inside your CS2 servers** (CounterStrikeSharp plugin).

## Recommended: install via CSM

CS2 Server Manager (CSM) is the easiest path (it installs **Metamod + CounterStrikeSharp + MatchZy Enhanced** and keeps everything updated).

- CSM quick start: `/docs/csm/quick-start`

## Manual installation (step-by-step)

### 1) Prerequisites

- CS2 dedicated server
- Metamod + CounterStrikeSharp installed and working
- .NET 8 runtime

### 2) Download the latest release

- Latest ME release: `https://github.com/sivert-io/MatchZy-Enhanced/releases/latest`

Download the `.zip` from **Assets**.

### 3) Extract to `game/csgo/`

Extract the archive into your server’s `game/csgo/` folder (keep the folder structure).

After extraction you should have something like:

- `game/csgo/addons/counterstrikesharp/plugins/MatchZy/MatchZy.dll`
- `game/csgo/cfg/MatchZy/`

### 4) Restart and verify

Restart your CS2 server, then in the server console run:

```text
css_plugins list
```

You should see MatchZy listed.
