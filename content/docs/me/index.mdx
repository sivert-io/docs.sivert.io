ME (MatchZy Enhanced) is an automated CS2 match management plugin for tournaments. It runs inside your CS2 servers to handle configs, match flow, events, stats, and (optionally) demo uploads while your tournament platform decides what to play.

## What you’ll find here

- Quick Start: install + first run
- Operators: installation, configuration, commands
- Developers: contributing and internals
- Reference: integrations, edge cases, changelog
