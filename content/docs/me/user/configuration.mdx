If you installed your servers with **CS2 Server Manager (CSM)** or you are running tournaments with **MAT**, you usually do **not** need to manually configure low-level MatchZy settings.

## Recommended setup (CSM / MAT)

- Use CSM to install and keep plugins updated: **[/docs/csm/quick-start](/docs/csm/quick-start)**
- Add servers in MAT and let MAT configure MatchZy automatically: **[/docs/mat/user/server-setup](/docs/mat/user/server-setup)**

### Quick sanity check (most common)

On the CS2 server console:

```text
css_plugins list
```

If MatchZy Enhanced is not listed, fix installation first: **[/docs/me/user/installation](/docs/me/user/installation)**.

## Manual / custom setups (advanced)

If you are not using MAT and want to configure MatchZy yourself, use these reference pages:

- **ConVars & commands**: `/docs/me/user/convars`
- **Config files**: `/docs/me/user/config-files`
- **Integration endpoints**: `/docs/me/user/integration-endpoints`
- **Examples**: `/docs/me/user/examples`
