title: Installation

If you are running tournaments with **MAT**, you should install MatchZy Enhanced using **CS2 Server Manager (CSM)**.

## Recommended: install with CSM

CSM installs CS2 servers and MatchZy Enhanced for you.

1. Follow the [CSM quick start](/docs/csm/quick-start)
2. Confirm MatchZy Enhanced is installed on your servers (CSM does this by default)
3. Add servers in MAT: `/docs/mat/user/server-setup`

## Manual install (advanced)

Use this only if you are **not** using CSM.

1. Download the latest release: [MatchZy-Enhanced releases](https://github.com/sivert-io/MatchZy-Enhanced/releases)
2. Extract into your CS2 server directory so MatchZy ends up under `game/csgo/`
3. Restart the server
4. Verify MatchZy loads (server console):

```text
css_plugins list
```

If you don’t see MatchZy, ensure CounterStrikeSharp is installed and working first.
