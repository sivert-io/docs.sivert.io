title: Installation
description: Install MatchZy Enhanced via CS2 Server Manager or manually.
---

## Prerequisites

- CS2 dedicated server
- CounterStrikeSharp installed and working (`https://github.com/roflmuffin/CounterStrikeSharp`)
- .NET 8 runtime on the server

## Option 1: CS2 Server Manager (recommended)

If you’re using MatchZy with MatchZy Auto Tournament, this is the easiest path.

1. Follow the [CSM quick start](/docs/csm/quick-start)
2. It will deploy one or more CS2 servers and install MatchZy Enhanced by default.

## Option 2: Manual install

1. Download the latest release: `https://github.com/sivert-io/MatchZy-Enhanced/releases`
2. Extract into `game/csgo/` so you end up with:
   - `game/csgo/addons/counterstrikesharp/plugins/MatchZy/MatchZy.dll`
   - `game/csgo/cfg/MatchZy/`
3. Restart the server and verify plugin load.
