title: Configuration

---

MatchZy reads configuration from:

- ConVars (`matchzy_*`)
- Config files under `cfg/MatchZy/`
- JSON match configs loaded from a URL (typically MatchZy Auto Tournament)

## Key integration convars

- `matchzy_loadmatch_url`
- `matchzy_remote_log_url` + optional header key/value
- `matchzy_match_report_url` (optional)
- `matchzy_demo_upload_url` (optional)

See the upstream doc for the full reference (migrated content will be expanded here over time).
