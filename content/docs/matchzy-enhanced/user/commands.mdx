This is a quick reference for common MatchZy Enhanced commands.

## Player commands

- `.ready` / `.unready`
- `.pause` / `.unpause` / `.tech` / `.tac`
- `.gg` (if enabled)

## Admin commands

- `.start` / `.forcestart`
- `.restart` / `.endmatch`
- `.forcepause` / `.forceunpause`
- `.roundknife`

## Diagnostics

- `matchzy_get_pending_events` (admin) — event retry queue status
- `matchzy_get_match_stats <matchId>` — pull match stats JSON from the server DB
