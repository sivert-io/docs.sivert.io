---
title: Build from source
description: Build the plugin locally and deploy to a server.
---

If you want to tweak the plugin and build it yourself:

```bash
git clone https://github.com/sivert-io/MatchZy-Enhanced.git
cd MatchZy-Enhanced
dotnet build
```

Copy build outputs into:

`game/csgo/addons/counterstrikesharp/plugins/MatchZy/`

And copy configs from `cfg/MatchZy/` into:

`game/csgo/cfg/MatchZy/`
