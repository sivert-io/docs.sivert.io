CSM (CS2 Server Manager) is automated multi-server management for CS2. It deploys multiple dedicated servers in minutes with competitive plugins, safe auto-updates, and tournament integration.

- Quick Start: install + first run
- Operators: day-to-day server management
- Developers: contributing and internals
- Reference: logging, updates, troubleshooting, changelog
