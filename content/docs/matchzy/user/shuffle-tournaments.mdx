---
title: Shuffle tournaments
description: Player-based tournaments with automatic team shuffling and balancing.
---

Shuffle Tournaments are designed for LANs and individual player competitions. Instead of fixed teams, players are reassigned to balanced teams each round based on their rating.

## Key features

- Individual competition (players, not fixed teams)
- Automatic team balancing
- Automatic round progression
- Player leaderboard

## Creating a shuffle tournament

1. Tournament → create
2. Choose **Shuffle Tournament**
3. Pick maps (number of maps determines number of rounds)
4. Set team size (2–10 per team)
5. Register players
6. Start tournament
