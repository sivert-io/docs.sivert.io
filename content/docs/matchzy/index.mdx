MAT (MatchZy Auto Tournament) is a web platform for running CS2 tournaments end-to-end (servers, teams, matches, veto, results) with minimal manual server setup.

It is inspired by the original **MatchZy** CS2 plugin, and is designed to work with **MatchZy Enhanced** (my fork with extra events/automation hooks).

## What you’ll find here

- Quick Start: install + first run
- Operators: admin setup and day-to-day tournament operations
- Teams & Players: public team pages, veto flow, connecting to servers
- Developers: contributing, architecture, testing
- Reference: production ops, reverse proxy, troubleshooting, changelog
