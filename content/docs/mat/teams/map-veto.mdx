title: Map veto
description: BO1/BO3/BO5 map ban/pick flow (CS Major style).
---

The map veto system lets teams ban/pick maps in a professional Counter-Strike format.

## Operator checklist (before the veto)

- Make sure the tournament uses **BO1 / BO3 / BO5** (veto is not used for Swiss/Round Robin).
- Make sure the selected **map pool** is reasonable (for standard veto flows: **7 maps**).

## When veto is used

Map veto is available for:

- BO1
- BO3
- BO5

Round Robin and Swiss use preset maps and don’t require veto.

## If teams get stuck

- Confirm both teams have the correct **team page link**
- Confirm the match is in the correct state (waiting for veto)
- If needed, use the match admin controls to **skip veto** and proceed (only as a last resort)

## Veto flow

### BO1 (CS Major standard)

```
1. Team A removes 1 map (first of 2)
2. Team A removes 1 map (second of 2)
3. Team B removes 1 map (first of 3)
4. Team B removes 1 map (second of 3)
5. Team B removes 1 map (third of 3)
6. Team A removes 1 map
7. Team B chooses starting side on remaining map
```

### BO3 (CS Major standard)

```
1. Team A removes 1 map
2. Team B removes 1 map
3. Team A picks Map 1
4. Team B chooses starting side on Map 1
5. Team B picks Map 2
6. Team A chooses starting side on Map 2
7. Team B removes 1 map
8. Team A removes 1 map
9. Team B chooses starting side on Map 3 (decider)
```

### BO5

```
1. Team A bans a map
2. Team B bans a map
3. Team A picks Map 1 (Team B picks side)
4. Team B picks Map 2 (Team A picks side)
5. Team A picks Map 3 (Team B picks side)
6. Team B picks Map 4 (Team A picks side)
```
