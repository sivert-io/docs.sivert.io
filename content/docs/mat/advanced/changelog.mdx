## 2.0.7 (January 28, 2026)

### Localization & tooling

- Large localization updates across multiple languages (Italian, Spanish, Portuguese, French, German, Dutch, Norwegian, Polish).
- Improved translation safety/consistency checks and added helper scripts for i18n syncing and fallbacks.

## 2.0.6 (January 25, 2026)

### Refactoring & settings

- Removed `PublicPages` component and streamlined routing structure.
- Streamlined authentication and match status handling for improved reliability.
- Added initial state for `allowSelfRegister` in settings for better player registration control.

## 2.0.5 (January 25, 2026)

### Access & authentication

- Added allocation status endpoint for player access control.
- Implemented direct access block for admin routes to prevent unauthorized access.
- Added test-only login endpoint for non-admin players to support development and testing.

## 2.0.4 (January 24, 2026)

### Authentication hardening

- Added signed `player_steam_id` cookie for improved admin authentication.
- Improved session handling for reverse proxy setups.
