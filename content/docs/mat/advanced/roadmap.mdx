This document outlines the current features available in MatchZy Auto Tournament.

> Live project status: [https://kan.sivert.io/MAT](https://kan.sivert.io/MAT)

## Highlights

- Tournament formats (Single/Double Elimination, Round Robin, Swiss, Shuffle)
- Server management and auto allocation
- Map & map pool management
- Team + player management (imports, public pages)
- Map veto system (CS Major formats)
- Match management (manual matches, recovery, simulation)
