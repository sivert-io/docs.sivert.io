Contributions are welcome — bug fixes, features, docs improvements, translations, or ideas.

## Quick start

### Fork & clone

```bash
git clone https://github.com/YOUR_USERNAME/matchzy-auto-tournament.git
cd matchzy-auto-tournament
```

### Install dependencies

```bash
yarn install
```

### Run locally

Follow the local dev docs:

- [Quick start](/docs/mat/quick-start)
- [Architecture](/docs/mat/developer/architecture)

## Reporting issues

Open an issue with:

- A clear description
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, Docker version, etc.)
