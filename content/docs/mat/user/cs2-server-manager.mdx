CS2 Server Manager (CSM) provisions and manages multiple CS2 servers preconfigured for MatchZy Auto Tournament.

See the dedicated docs at `/docs/csm`.

## High-level flow

1. Install and bootstrap servers with CSM
2. Add servers in MAT under **Servers**
3. Ensure webhook base URL + `SERVER_TOKEN` are set
4. Run tournaments — MAT will allocate servers automatically
