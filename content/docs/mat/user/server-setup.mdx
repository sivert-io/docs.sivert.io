This page is written for **tournament operators**. The goal is simple: get servers online, add them to MAT, and make sure they can talk to each other.

## Recommended setup (CSM)

If you’re running more than one server, use **CS2 Server Manager (CSM)**. It installs CS2, MatchZy Enhanced, and keeps things consistent.

1. Install and run CSM: **[CSM quick start](/docs/csm/quick-start)**
2. In MAT, go to **Servers** and add your servers (host/port/RCON).
3. Wait for each server to go green/healthy.

If you see warnings, use: **[Server health (common warnings)](/docs/mat/user/fleet-health)**.

## Manual setup (advanced)

Use this only if you are not using CSM.

### 1) Install prerequisites on the CS2 host

- Install Metamod + CounterStrikeSharp (CSS)
- Install MatchZy Enhanced (so it appears in `css_plugins list`)

MatchZy Enhanced docs: **[/docs/me](/docs/me)**

### 2) Configure RCON (MAT → server)

Set a correct RCON password and port in your server config:

```ini
rcon_password "your-secure-rcon-password"
hostport 27015
```

Then, in MAT → **Servers**, add the server with the same host/port/password.

### 3) Verify webhook reachability (server → MAT)

Your CS2 host must be able to reach the MAT API. From the CS2 host:

```bash
curl http://your-mat-host:3069/api/events/test
```

You should see:

```json
{ "success": true, "message": "events route is working" }
```

If this fails, fix DNS/firewall/reverse-proxy first.

## After any change: refresh status

After updating configs, plugins, or CS2 itself:

1. Restart the server(s)
2. Refresh servers in MAT (Servers page)
