Manual matches are for one-off games that are **not part of a tournament bracket**.

## When to use manual matches

Use manual matches when you want to:

- Spin up a one-off scrim or test match
- Run a showmatch outside a bracket
- Quickly create a match between two teams or ad-hoc lineups

## Creating a manual match (UI)

1. Go to **Matches**
2. Click **Create Manual Match**
3. Fill out the modal:
   - Basic info (slug, server)
   - Teams
   - Maps & Rules (format, max rounds, overtime)
4. Save — MAT creates the match and loads it on a server.
   - If you selected a server, it loads there
   - If you leave server empty, MAT can auto-allocate a server when one is available

## Running the match

Players join using the connect string shown in the match page, then follow the normal flow:

- join server
- `.ready`
- play

If something goes wrong (server down / CS2 update required / IP banned), see:

- **[Server health (common warnings)](/docs/mat/user/fleet-health)**

## Notes

- Manual matches are separate from tournaments/brackets.
- If you want a full tournament flow (teams, veto, bracket), use **Tournaments** instead.
