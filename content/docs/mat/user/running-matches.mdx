## Match flow

### 1. Tournament start

**For BO1/BO3/BO5 (with veto):**

- Teams complete map veto
- System attempts to auto-allocate a server
- If no server is available, the system polls until one is available
- Match loads automatically on the server

**For Round Robin/Swiss (no veto):**

- System immediately allocates servers
- Matches load automatically

### 2. Warmup phase

Players connect to the server:

```
connect 192.168.1.100:27015
```

- Players auto-assigned to the correct team
- Type `.ready` when ready
- Match start is controlled by MatchZy “ready” settings (configured by MAT)
  - By default, MatchZy requires **2** ready players (`matchzy_minimum_ready_required=2`)
  - Your admins can change this in **Settings** (MatchZy defaults), or force-start when needed

### 3. Live match

Real-time updates show:

- Current score
- Round number
- Match phase (live, halftime, overtime, paused)

### 4. Match complete

- Winner auto-determined
- Bracket auto-updates
- Demo file uploaded (if demo recording + upload is configured)
- Server freed for next match

## Admin controls

Available from the match details modal.

### Match control

- Pause / unpause
- Swap teams
- Restart round

### Advanced actions

- Skip veto
- End warmup (force start)
- End match / restart match
- Restore backup
- Broadcast message
- Change map

### Player management

- Add backup player (substitute mid-match)
