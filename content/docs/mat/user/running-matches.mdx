This page explains the operator view of a match: what happens, what to tell players, and what to do when something goes wrong.

## Match flow (what you’ll see)

### 1. Tournament start

**For BO1/BO3/BO5 (with veto):**

- Teams complete map veto
- MAT allocates a server when one is available
- Match loads automatically on the server

**For Round Robin/Swiss (no veto):**

- MAT allocates servers and loads matches automatically

### 2. Warmup phase

Tell players to join the server using the connect string shown in the match page, for example:

```
connect 192.168.1.100:27015
```

- Players auto-assigned to the correct team
- Players type `.ready` when ready
- If you need to start anyway, use the match admin controls (see below)

### 3. Live match

Real-time updates show:

- Current score
- Round number
- Match phase (live, halftime, overtime, paused)

### 4. Match complete

- Winner auto-determined
- Bracket auto-updates
- Demos upload automatically if enabled
- Server freed for next match

## Admin controls

Available from the match details modal.

### Match control

- Pause / unpause
- Swap teams
- Restart round

### Common operator actions

- Skip veto
- Force start / end warmup
- End match / restart match
- Restore backup
- Broadcast message
- Change map

### Player management

- Add backup player (substitute mid-match)

## Common problems

### Players can’t connect / server is down

Start here:

- **[Server health (common warnings)](/docs/mat/user/fleet-health)** (offline, IP banned, CS2 update required, Plugin DB DOWN)

If the match is staged (ready/loaded) on the wrong server, you can also use the match admin controls to reallocate the server (when available).
