This page summarizes what MatchZy Auto Tournament can do.

## Tournament management

- Single/double elimination, round robin, swiss, shuffle
- Bracket generation and regeneration
- Real-time bracket updates

## Match system

- Auto server allocation
- Automatic match loading
- Live match status, scores, and connection tracking
- Demos upload and downloads
- Out-of-date server safeguards (prevents allocating matches to outdated servers)
- Server reallocation tooling (move a staged match to a different server if needed)

## Maps and veto

- Map + map pool management
- CS Major-style veto for BO1/BO3/BO5

## Admin tools

- Match controls (pause, restore backup, swap teams, etc.)
- Server events monitor
- Match recovery tooling
- Server health monitoring (clear warnings + guided fixes for common issues)
- Faster server initialization (smoother server onboarding)
