This page is for **tournament operators**. It explains how to make sure the right maps appear in MAT and how to build map pools for tournaments.

## The quick version

- Use **Active Duty** if you’re unsure.
- For standard veto formats, use a pool with **7 maps**.
- If maps are missing, run **Sync CS2 Maps** in MAT Settings.

## Sync the map list (recommended)

If you don’t see the maps you expect:

1. Go to **Settings** in MAT
2. Click **Sync CS2 Maps**
3. Wait for the success message

This updates the map list without breaking existing tournaments.

## Create a map pool

1. Go to **Maps & Map Pools**
2. Create a new pool
3. Add your maps
4. Save

### Tip: veto-friendly pools

For BO1/BO3/BO5 veto formats, you typically want **exactly 7 maps** (standard “CS Major style” veto).

## Troubleshooting

- **My pool has the wrong number of maps**: create a new pool with **7 maps**, or use **Active Duty**.
- **Map images don’t show**: re-upload the image/thumbnail for the map.
- **Teams can’t veto**: make sure your tournament match format is BO1/BO3/BO5 and that a map pool is selected.
