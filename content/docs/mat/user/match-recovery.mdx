This page is for **tournament operators**. Use it when MAT or your server host restarts mid-tournament and you need to get back to a stable state.

## When you need recovery

- MAT was restarted during a live match
- A server was restarted and the match UI looks “stuck”
- The bracket/match page doesn’t reflect what’s happening on the server

## What to do first (safe steps)

1. Go to **Servers** and fix any fleet warnings first:
   - **[Server health (common warnings)](/docs/mat/user/fleet-health)**
2. Go to **Matches** and open the affected match.
3. Check:
   - Is the server online?
   - Are players connected?
   - Does the match show Live/Warmup/Ended?

Often, just refreshing server status + waiting a minute is enough after a restart.

## Use the Match recovery tool

1. Go to **Match recovery** in the sidebar
2. Run recovery
3. Re-open the match page and confirm the match state is correct

## If recovery doesn’t work

- Check server logs (CSM users: `sudo csm attach <server>` or `sudo csm logs <server> 200`)
- Check MAT logs (Docker users: `docker compose logs -f matchzy-tournament` in your MAT folder)
- If a match is staged on the wrong server and players can’t connect, reallocate the match to another server (Admin controls).
