# docs.sivert.io

This repo hosts **`docs.sivert.io`** — a unified documentation site for my projects:

- **MAT** (MatchZy Auto Tournament)
- **ME** (MatchZy Enhanced)
- **CSM** (CS2 Server Manager)

Built with **Next.js** + **Fumadocs**.

## Local development

```bash
yarn install
yarn dev
```

Then open `http://localhost:3000`.

## Scripts

```bash
yarn types:check
yarn build
```

## Deployment

Deployed on **Vercel**. No special environment variables are required for the core docs site.
